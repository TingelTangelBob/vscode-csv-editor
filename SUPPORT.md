# Support

## The file opens as text

Right-click its tab → **Reopen Editor With…** → **CSV Simple Editor**. Check **Open CSV/TSV in table by default** in settings if you want this for future files.

## Columns or characters look wrong

Check the delimiter in the editor settings and the file encoding in VS Code's text editor. Supported delimiters are comma, semicolon, tab, and pipe. The first record is treated as column names.

## Screenshots are missing

README screenshots load from GitHub over HTTPS. Check that your connection or proxy allows `raw.githubusercontent.com`. Table editing and exports work offline.

## A large file loads slowly or a problem persists

[Report a bug](https://github.com/TingelTangelBob/vscode-csv-editor/issues/new?template=bug_report.yml) with the extension and VS Code versions, operating system, approximate file size, and steps to reproduce it. Include a small anonymized CSV sample when possible. Do not attach the entire source dataset just to demonstrate a few problematic rows.

[Request a feature](https://github.com/TingelTangelBob/vscode-csv-editor/issues/new?template=feature_request.yml) or read the [user guide](docs/GUIDE.md).
